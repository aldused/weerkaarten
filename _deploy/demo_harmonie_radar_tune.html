Harmonie 43 — gesimuleerde radar — kalibratie-vergelijk

Vier renderings van dezelfde Harmonie 43 mm/u-data. V1 = huidig op weerlab.nl. V2/V3/V4 = voorstellen.
—

V1 — Huidig (Marshall-Palmer Z=200·R1.6)

Levels elke 5 dBZ. 4 grijstinten −5/0/5/10 dBZ. Donkergroen op 25, donkergeel op 35, donkerrood op 50.

V2 — Kleurschaal getuned (zelfde Z-R)

Marshall-Palmer ongewijzigd. Kleurschaal monotoon helder oplopend, geen grijstrappen, geen wit-glitch op 70.

V3 — V2 + NEXRAD Z-R (Z=300·R1.4)

Convectieve Z-R relatie (KNMI/NEXRAD-stijl). Lichte regen oogt iets sterker, zware buien iets feller.

V4 — V3 + peak-boost (1.6× R bij >0.5 mm/u)

Compenseert dat 1u-gemiddelde mm/u de instantane radar-piek onderschat. Convectieve cellen krijgen hun rode kern terug.
Vergelijking met Wouter / Infoplaza: Wouter toont waarschijnlijk de Harmonie native simulated reflectivity (REFC), instantaan. Wij hebben alleen het 1u-cumulatieve neerslagveld in de KNMI Open Data publicatie van Harmonie 43, dus we *moeten* via Z-R reconstrueren. V4 lijkt het meest op zijn output. Toets: ←/→ stappen, spatie speelt.
