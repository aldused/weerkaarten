Over deze demo. Data komt live van de WeatherPro point-forecast API (point-forecast-weatherpro.meteogroup.com, MeteoGroup/DTN) — dezelfde bron als de app, maar rechtstreeks per lat/lon. Echte uurlijkse verwachting.
  • Plaatskiezer: elke locatie werkt via geocoding → lat/lon; geen app meer nodig. Nu Rotterdam, Dordrecht en Soestdijk.
  • Wind & stoten in km/u, dauwpunt direct uit de API, bewolking in octa (0–8), zon in minuten per uur (max 60).
  • Tijden zijn lokale tijd (Europe/Amsterdam).
  • Let op (licentie): dit is DTN/MeteoGroup’s commerciële data via een WeatherPro-web-token. Prima voor demo/eigen gebruik; publiceren op weerbewaking vraagt een licentie-check.
